# PHASE 27 - FROZEN PROSPECTIVE ANALYSIS PLAN
Date: 2026-10-24. Written before Phase 27 outcome evaluation.

Scope: Exploratory, prospective *analysis* of previously inspected 1885/1887/1888 archive data, NOT independent confirmatory evidence. Earlier projects/phases frozen. No historical attitude, meaning, political identity or sentiment labels inferred.

Research question: Are observed text-based 1885-vs-1888 newspaper-period differences transferable across the two newspaper domains, and can a corpus-composition intervention on BPE vocabularies alter the apparent period distinction with texts and classifiers held fixed?

Material: Phase26/windows.jsonl (90 alphabetic-word mid-paragraph windows from corrected XhTxt; exactly 581 unique windows across 1885,1887,1888), original data source TxtLangFiles1870-1894_TB.zip. Use 1887 exclusively to train *unlabelled* tokenizers; use 1885 and 1888 to learn/test period classification. Do NOT tune against period test outcomes. Sampling was originally developed for prior phase, so 1888 is not new independent holdout.

BPE intervention: total 60,000 alphabetic training characters from 1887 only, 1000 vocab, SentencePiece BPE, identity normalization, coverage 1.0. Composition: 0%, 50%, 100% IMVO. For 0 and 100, take entirely matching source, and for 50% take 30,000 characters from each source. Fix seeds 27, 28, 29, randomize 1887 window order within source. Reuse same source sample per seed across mixtures. All tokenizer training inputs and model hashes recorded. No 1885/1888 data in tokenizer fitting. NB 1887 is shared with older studies, so independent-confirmation claims prohibited.

Primary period evaluation: For 1885 and 1888 windows only, four leave-months-out folds. Fold f (0..3) tests months m if (m-1)%4 == f, train on other 9 months. For each of two training newspapers, train period classifier on only that newspaper's 1885/1888 training windows; evaluate same trained classifier on held-out months in BOTH newspaper domains. Thus 4 prediction cells per method: train IMVO -> test IMVO, train IMVO -> test ISIG, train ISIG -> test IMVO, train ISIG -> test ISIG. All validation is issue/month blocked; no issue is in both train/test for a fold. Balanced logistic regression C=1, liblinear solver, class_weight=balanced, random_state=27. Word/char TF-IDF fitted only on labelled training fold; BPE ngram TF-IDF fitted only on labelled fold with tokenizer models fitted on 1887. No additional hyperparameter search.

Fixed text representation methods: (i) word unigram TF-IDF min_df=2, max_features=30000, (ii) char_wb 3-5 TF-IDF min_df=2, max_features=30000, (iii) BPE token unigram TF-IDF using 3 source mixes x 3 seeds; max_features=30000, min_df=2. The same 1885/1888 text is used across models. Inference with fixed vocabulary; C=1 across representations.

Preplanned robustness: Repeat all models after removing entire words containing any of (imvo,isigidi,samaxosa,zabantsundu,bantsundu,ntsundu,mnyama,xosa,jabavu,gqoba,makiwane) and exact tokens (mr,sir,lovedale,b,g,e,th). This aggressively removes some meaningful content and is a sensitivity test only. Keep remaining text without replacement and account for changed length. Optional root counts are secondary descriptive checks using two already-published identity strings (ntsundu,mnyama) compared against exact abantsundu/abamnyama, with no semantic ground truth.

Metrics: primary balanced period classification accuracy computed over newspaper issues (each issue has equal weight; average the 1885 issue-level accuracy and 1888 issue-level accuracy for each train/test newspaper pair). Also report page-weighted BA but do not use it to pick models. For each method, define `within` as average of two same-newspaper cells, `cross` as average of two cross-newspaper cells. Transfer gap = within - cross. Uncertainty resamples 12 calendar months with replacement (2000 replicates, seed 27001), preserving issue/page clusters and both titles, and reports paired 95% percentile CIs. Report per-newspaper/per-year counts, calibration if available, and exact results. Do not treat months as an infinite random population. The same 12 month labels appear in each year.

Hypotheses and accept/reject gates (will not be moved):
H27a: On the original, unmasked text, *both* within-newspaper char-TFIDF balanced accuracies exceed 0.60. If either <=0.60, reject this composite criterion.
H27b: Original char-TFIDF cross-newspaper transfer gap is at least 0.10 (10 percentage points) and paired month-bootstrap 95% interval is entirely above zero. If either condition fails, reject.
H27c: Across BPE models, changing the source mixture from 0 to 100% changes at least one of the two *cross-newspaper* accuracy estimates by >= 0.05 (5 percentage points) in its mean over seeds AND the corresponding paired month-bootstrap 95% CI excludes zero. Otherwise reject. This is a representation-policy impact, not proof of semantic mistakes. Other mixtures and masked contrasts are descriptive.

Negative/sanity controls: true period labels within source/year are balanced per class in the metric; every test issue/month excluded from its fold's supervised training; no future 1888 pages in BPE training; shuffled-label diagnostics may be added ONLY if precommitted as separate analyses, not to salvage rejected hypotheses. For BPE, report vocab size and character budget. Check that baseline char source-classification result from Phase26 is unrelated to target labels; never call source prediction political-ideology prediction.

Study decisions: Phase27 may show no transferable period signal, or BPE effects too small to matter; that is scientifically meaningful negative evidence. Source, year, genre, editorial and OCR artifacts still confounded; 1885 item-level genre labels are not in supplied files. No paper drafting requested. Keep code, frozen protocol, sample-level predictions, issue-level uncertainty, hashes, failures and conclusion.
