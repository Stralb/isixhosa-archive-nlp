# Phase 2 precommit - partial and unknown archival selection benchmark

Frozen design: 2026-10-24. **No Phase-2 outcome evaluations were inspected before creating this protocol.** Phase 1 results and 1885 page counts were previously available; this is a *new simulation holdout* rather than an independent historical corpus.

## Question and target
Can standard provenance-stratified means, propensity weighting, or existing missing-data bounds make defensible decisions when the archive's selection mechanism is partly unknown or off support? We benchmark failure modes, NOT propose a new algorithm. Target is the **finite 1885 archive page-uniform mean of a clipped lexical word-form rate**, and its synthetic period B minus A difference. This target is not a measure of semantics, historical speaker beliefs, or publication beyond the archived pages.

For each page and word form: `Y=min(count/number_of_alpha_tokens, 0.02)`. Thus Y is provably in [0,0.02]. Same collection of pages appears in counterfactual period A/B; only artificial B counts may change. The target averages all *pages* equally, independent of their length. The total source/page inventory is an **optimistic complete administrative audit frame**, revealing all page IDs, source, half, issue, date, and word totals for every missing item, but not the hidden text. Without such a frame, the finite-population target and the given bounds cannot be computed, and identification is worse.

## Fixed splits and candidate features
Use only Phase1 verified `counts.npz`, `pages.csv`, `features.csv`, and original source ZIP for verification and text-reuse flag. Preserve original 200 candidate common word forms as the eligible pool. Sort issues independently within IMVO/ISIG by SHA256(`'P2-SPLIT-20261024|' + issue`). Per source allocate first 60% of issues to TRAIN, next 20% to DEV and the rest TEST (integer floor for first two). No issue shared across splits. Select the top 80 pool features by counts in TRAIN, with lexical tie break. Although the 200-candidate pool was previously derived from all 1885 issues in Phase1, rankings and injected signals are chosen in TRAIN only; the pool is not independent of TEST. Signal ranks among the 80 TRAIN-ranked features: UP = 18,24,30,36,42,48 (0-indexed); DOWN = 6,8,10,12,14,16. The remaining 68 are null. No semantic annotations.

## Worlds and selection
World NULL: period A and B complete page counts identical, target change exactly zero for all forms. World INJECTED: B is a coherent per-page counterfactual count table generated once per split from seed 2026102411: each DOWN feature has Binomial(current count, 0.40) occurrences replaced with background forms, and a Binomial(background token pool, 6*0.00085) count is allocated by Multinomial equally to the six UP forms. All token totals remain fixed; other measured feature forms are unchanged. All observable masks are reused between null and injected worlds so paired differences are meaningful. The injection is a **simulated lexical-form substitution**, not validated change of historical word senses. Exact oracle finite population effects saved, never provided to estimating methods.

Six masks: (1) `MAR_SOURCE_PAGE`, A/B source-half retention probabilities reversed; (2) `MAR_LENGTH_DATE`, page metadata-dependent logistic selection; (3) `MNAR_LATENT`, retention inversely associated across periods with a full-text word-rate proxy unavailable for missing text; (4) `ISSUE_DROPOUT`, entire issues missing together; (5) `ZERO_CELL`, no Isigidimi back-half page observed in B; (6) `REPEAT_PREF`, inverted propensity for text with cross-issue identical 13-word sequences. All selection masks generated without conditioning on injected target changes. The text-reuse flags are used **only by the simulation**, and would not ordinarily be available for unobserved documents. Record exact inclusion propensities for oracle diagnostics.

Replicates per scenario = 80 DEV and 160 TEST, with fixed scenario/split-specific RNG seeds from SHA256 IDs. No tuning to TEST results, no test-specific changes after observation; all post-freeze issues must be documented. Within DEV/TEST, evaluate all 80 forms in both worlds. Repeat selection on the same finite archive is simulation replication, not independent evidence.

## Baselines and intervals
Point methods: (i) raw observed page mean (`POOLED`), (ii) source-half poststratification to full-frame weights (`STD`), (iii) equal-cell matched page count estimate (`MATCH`), (iv) oracle known-inclusion Horvitz-Thompson (`KNOWN_IPW`), (v) logistic estimated-propensity Hájek (`EST_IPW`) using only full-frame observed metadata plus missingness labels. Known propensities are **non-deployable** and not usable with unknown MNAR selection. Explicitly fail standardized and matching estimates in any source-half cell lacking observations in either period. Known HT fails if any positive target cell has zero inclusion probability. Estimated-IPW can give unsupported extrapolations under zero cells; flag rather than present as valid.

Set-valued methods: (vi) exact worst-case bounded-outcome Manski-style interval (`MANSKI`) with page-missing fractions from known frame and 0<=Y<=.02; (vii,viii) source-half pattern-mixture sensitivity intervals (`GAMMA_0005`, `GAMMA_0020`) assuming for each period/cell the **mean missing Y** differs from observed cell mean by no more than respectively 0.0005 or 0.0020. If a cell is unobserved, use the unconditional [0,.02] bound. These latter assumptions are not established as true; report actual assumption violations using the simulated complete-data oracle, and never imply unconditional coverage or a formal 95% CI.

The set bounds are finite-population identification intervals, **not confidence intervals**. Primary metrics per scenario/world/split: mean absolute point-estimation error; null spurious sign decisions and injected correct-sign detection for point estimates at a fixed practical absolute threshold 0.00075 (7.5/10k); percentage non-estimable due to nonpositivity; for bounds, true-effect inclusion rate, width and fraction sign-resolved (interval wholly >0 or <0), plus false-sign rate and injected-sign recovery. For sensitivity intervals, additionally check the posited missing-mean gap empirically. All metrics must be computed separately for NULL and INJECTED and across each mask type. No unjustified nominal coverage or significance p-values; calibration of 95% *sampling* intervals is deferred to a later phase and must not be conflated with identification-set coverage.

## Gates
PASS benchmark if (a) at least one hard scenario creates a reproducible estimation or sign-coverage failure in strong *implementable* baselines and (b) the exact bounds display valid but potentially low-decision-coverage behavior; KILL a novel-method claim if oracle, feasible stratification or simple sensitivity methods already resolve test problems at useful decision coverage. An observed difficult scenario does NOT alone prove novelty; competitive prior-method and external-corpus tests are in Phases 3 and 5. No method is allowed to decide positive/negative when bounds include zero and claim assumption-free identification. Independent verification must reconstruct raw counts from source ZIP, validate every split, injection accounting, selection mask, and compute primary metrics from stored per-example arrays. Fresh-ZIP extraction and deterministic replay required.
