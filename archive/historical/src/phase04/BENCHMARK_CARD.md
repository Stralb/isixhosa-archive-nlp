# Phase4 benchmark card — value of archival evidence

Study unit: page, nested in original issue. Paired split: 1884/85 DEV (496 pages), 1887/88 TEST (588 pages). The benchmark has 80 development-selected lexical word forms and two virtual counterfactual worlds; it is NOT human-labeled semantic change. All period comparisons use different real historical issues.

Source: Phase3 frozen benchmark counts, page metadata and masks. They derive from the user-supplied archive ZIP SHA256 375c5864e180717f34403287e502cf8812b038baf5a8fb4ae8ee8cdb2be321d5. Raw text not rebundled; pages are cropped/translated only in earlier digitization, not in this phase. Phase3 is treated as immutable.

Simulation factor: fraction of hidden page word counts hypothetically revealed in nested audit policies (random, theoretical width-optimal period, cover empty source-half cells). Record exact recovered pages, no query of masked lexical values. Even selected pages have synthetic "recovery" because the original ZIP already contains them; public archives supplied no actual previously missing source text in this experiment.

Main endpoint: arithmetic sharp identification interval for a page-uniform clipped lexical-rate difference, not a 95% interval. A bound that excludes +/-2/10000 licenses a sign statement for the entire frozen finite digitized sample. Baselines are original Phase3 Manski (at q=0) and the same bound with extra verified (simulated) counts. This analysis is a classic value-of-information evaluation, not a proposed new estimator.

Metrics: bound width, practical-sign issue frequency, fraction of uncovered cells, complete finite-archive truth inclusion, false sign calls (guaranteed zero under sharp model), cost as fraction of originally hidden pages. Outcomes across simulated masks are dependent because they share the same historical pages; descriptive averages are not independent-sample confidence intervals.

The source/page census and every page's original word total are optimistically available even when its word-form counts are hidden. Real-world omitted print runs may lack this administrative frame entirely. No historical cultural, ideological, editorial or morphological explanation is inferred from mechanical form counts.
