The scientific write-up is **a draft pending author, ethics and archival-rights sign-off**. It is not final coursework submission merely because it compiles.

We placed the equivalent layout commands in the accompanying \`ccn.sty\`, while preserving the original user-provided ZIPs in the conversation's downloadable attachments for fidelity and comparison.

## Draft components

- \`report.tex\`: two-page scientific narrative, followed by references, the editable 2024 checklist, and placeholders for Wits Faculty ethics declaration and group contribution statement.
- \`paper_references.bib\`: six references with source links, verified against ACL Anthology and Cambridge.
- \`ccn.sty\`: CCN 10pt two-column formatting.
- \`neurips_checklist_filled.tex\`: all 15 NeurIPS questions. Answers \`[REVIEW]\` require human confirmation, and every answer must be checked.
- \`make_figure.py\`: a deterministic two-panel figure from frozen verified numeric results.
- \`figures/main_evidence.pdf\`: generated by the script above (not required to be manually edited).

## Build

From the repository root:

\`\`\`bash
python -m pip install -r requirements.txt
python reports/make_figure.py
cd reports
latexmk -pdf -interaction=nonstopmode -halt-on-error report.tex
\`\`\`

Requires TeX Live packages for \`apacite\`, \`pslatex\`, \`caption\`, \`graphicx\`, \`hyperref\`, \`microtype\`, and \`helvet\`; \`ccn.sty\` is committed locally.
