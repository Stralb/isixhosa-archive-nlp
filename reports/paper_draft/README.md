# Earlier paper draft (26 October 2026)

This folder holds the previous extended-abstract draft, its figures and the original CCN style files. The [current manuscript](../../paper/README.md) is in `paper/`.

The archived PDF is [`report.pdf`](report.pdf); it should not be used as the 27 October submission.

To rebuild this older version, install `matplotlib` and `numpy`, run `python make_figure.py`, then compile `report.tex` with `pdflatex` and `bibtex8`. The style files `ccn.sty` and `apacite.bst` are also used by the current paper's Makefile.
