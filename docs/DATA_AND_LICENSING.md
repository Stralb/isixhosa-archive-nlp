# Data provenance and licensing status

**Source:** Course-supplied historical newspaper transcription archives associated with the IsiXIT project (Schoots et al., 2023). See the [dataset publication](https://aclanthology.org/2023.rail-1.7/) and [archive checksums](../data/README.md).

## Current repository state

The **public repository already tracks two source ZIP files** under [`data/`](../data/): `TxtLangFiles1870-1894_TB.zip` and `TxtFiles1870-1894_TB.zip`. They are not merely local placeholders.

We **have not verified permission to redistribute** these course-provided transcriptions or their underlying archival content. GitHub availability and a course handout do not by themselves prove a redistribution licence. The maintainers must check source terms with the archive/course owners before treating the ZIPs as an open dataset.

If distribution is not permitted, stop sharing the ZIPs and follow an approved data-access procedure. Deleting a file in a later Git commit **does not erase earlier public Git history**; dealing with existing Git history and downstream copies is a separate remediation task. Do not rewrite Git history without an explicit group decision.

The project also does **not yet have an author-approved software licence**. A public repository without a licence should not be described as open-source licensed. Do not add MIT/GPL/Apache licensing without agreement from all relevant rightsholders.

## Responsible use

`EnTxt` and `XhTxt` are **archive-assigned text views**, not validated language labels. The experiments do not provide information about individual historical authors or evidence of societal discrimination. Avoid re-identification and unsupported linguistic/cultural claims.

See [methods](../reports/methods.md), [submission status](../paper/author_review/submission_status.md) and the [paper-to-evidence guide](../reports/PAPER_TO_EVIDENCE_GUIDE.md).
